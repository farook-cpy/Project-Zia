Step-by-Step Installation & Deployment Flow

01
Preparing the Sony Xperia 1 III Server Node Termux / Android

Install Termux and Termux:API from F-Droid. Enable persistent wake-lock to prevent Snapdragon 888 deep sleep, and set Sony Battery Care limit to 80% to preserve battery lifespan during 24/7 plugged operation.

termux-wake-lock
pkg update && pkg install python git termux-api sqlite clang
git clone https://github.com/your-repo/project-zia.git && cd project-zia
pip install -r requirements.txt && python server.py
02
Linking LifeDesk SQLite Database (Habits & Finance) Local Database

Connect Zia's backend directly to your existing LifeDesk SQLite databases (habits.db and finance.db). Enables sub-millisecond, zero-cloud natural language habit logging and expense aggregation.

# Place existing databases in data/lifedesk/ or point .env path
LIFEDESK_HABITS_PATH=data/lifedesk/habits.db
LIFEDESK_FINANCE_PATH=data/lifedesk/finance.db
03
Connecting Smart Home IoT & Wireless ADB Bridges ESP8266 / ADB

Configure local IP addresses for your ESP8266/NodeMCU relays (Tasmota/Shelly/WLED) and authorize wireless ADB pairing (port 5555) on your bedroom Android projector and family tablet.

adb connect 192.168.1.65:5555 # Android Projector
adb connect 192.168.1.75:5555 # Android Tablet
IOT_DEVICE_IP=192.168.1.50 # ESP8266 Desk Lamp Relay
04
Remote Telegram Gateway & Neural TTS Voice Notes Away-From-Home

When away from your local Wi-Fi, the bi-directional Telegram gateway allows you to send commands, query prayer schedules, and receive neural Edge-TTS voice note responses directly inside your personal Telegram chat.

TELEGRAM_BOT_TOKEN="your_bot_token"
TELEGRAM_ALLOWED_USER_ID="your_telegram_id"
05
Agent-Browser CDP Automation & Family OTP Sink Web Automation

Enables token-efficient accessibility tree parsing (@e1, @e2 tokens under 50 tokens) for web actions, and opens a secure local webhook (POST /api/webhook/notification) to capture family OTPs automatically.

# Query latest OTP via voice or terminal:
zia> what is the latest otp
# "Latest OTP is 849201 from VK-SBIINB (12s ago)."
⚠
Thermal & Memory Sentinel: Always keep subagent concurrency capped strictly to max_workers=2 in engine/subagents.py to prevent thermal throttling on the Snapdragon 888 chip.
