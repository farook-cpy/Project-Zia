==================================================
TianYeLulu Live2D Model Asset Directory
==================================================

Drop your extracted model files into this folder:
- TianYeLulu.model3.json (Master descriptor)
- TianYeLulu.moc3 (Live2D binary model data)
- TianYeLulu.physics3.json (Physics calculations)
- TianYeLulu.cdi3.json (Display info / parameters)
- textures/ (Subfolder containing PNG atlas files)
- expressions/ (Subfolder with .exp3.json files for F1 - F11 hotkeys)
- motions/ (Subfolder containing idle and motion files)

When files are placed here, the local engine and WebGL canvas will load TianYeLulu immediately with zero configuration changes.
